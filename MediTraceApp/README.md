# MediTrace V2 — Premium Pillbox update

1. Back up your current MediTraceApp folder.
2. Extract this ZIP into your MediTraceApp folder (overwrite files when prompted).
3. Keep running Live Server, then press Ctrl+Shift+R in the browser.
4. From Home or Settings select **Upgrade to Premium** to view the smart pillbox picture.

This build uses the original V2 index.html and style.css and updates the supplied script.js only in the premium() function. The image is stored at images/pillbox.png. All Premium and connectivity features remain presentation demos, not operational medical hardware integrations.
